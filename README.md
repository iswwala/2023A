## 问题一方法概述

问题一在题面规定的 12 个代表日、每天 5 个太阳时上建立 60 个太阳状态。对每个状态和每面定日镜，程序依次完成：

1. 根据纬度、赤纬角和时角计算太阳高度角、方位角、太阳向量与 DNI；
2. 由太阳方向和镜心至接收器中心方向的角平分向量确定镜面法向；
3. 在有限 `6 m x 6 m` 镜面与半角 `4.65 mrad` 的均匀太阳盘上建立联合低差异样本；
4. 沿同一条光线依次判断入射阴影、逐方向反射、出射遮挡和有限圆柱侧面命中；
5. 计算阴影遮挡效率、余弦效率、大气透射率、条件截断效率与综合光学效率；
6. 乘以 DNI、镜面面积和反射率，得到逐镜、镜场、月平均与离散年平均输出。

正式 M1 使用每面镜 64 个镜面样本、每个状态 32 个太阳盘方向和 4 个固定扰动种子。B1 使用 `5 x 5` 镜面中点网格及 16 个太阳盘方向，仅作为可运行的低分辨率基线，不能替代 M1。

## 数据与证据流

```text
题面附件
  -> 数据审计与清洗
  -> workspace/data_clean/Q1/heliostat_positions.csv
  -> M1 主方法与 B1 基线
  -> results/Q1/experiments/round1/
  -> 代码审查与稳健性检查
  -> frozen_numbers.json
  -> 中文论文图和 paper/sections/q1.tex
  -> paper/main.pdf
```

论文数值必须遵循“程序 -> 正式结果 -> 冻结 -> 论文”的方向。不要手工编辑 `frozen_numbers.json`；任何可能改变冻结结果的模型、参数或输入修改，都必须记录解冻原因、重跑受影响实验并重新冻结。

## 复现与编译

仅运行几何和实现一致性验证：

```bash
python scripts/Q1/q1_optical_model.py validate
```

重新执行问题一全部正式实验：

```bash
python scripts/Q1/q1_optical_model.py all --backend tensorflow --batch-size 128
```

正式运行会覆盖 `results/Q1/experiments/round1/` 中的规范结果，当前记录耗时约 312 秒。若运行结果或规范输入发生变化，已有冻结文件将失效，必须按解冻流程处理，不能直接让论文继续引用旧数值。

在结果已经获得人工批准后重新生成冻结数值和论文图：

```bash
python scripts/Q1/freeze_q1_numbers.py
python scripts/Q1/generate_q1_paper_figures.py
```

编译论文：

```bash
cd paper
latexmk -xelatex -interaction=nonstopmode main.tex
```
