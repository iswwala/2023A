# 问题一论文写作证据包

## 1. 使用边界

本文件是问题一论文写作的单一入口。正文数值只能来自同目录下的 `frozen_numbers.json`；模型结构以 `workspace/methods/Q1/q1_final_method_explanation.md` 为准；稳健性解释以 `robustness/Q1/q1_robustness_report.md` 为准。不得从探索性输出或旧英文诊断图中另取数值。

人的判断来源如下：M1方法选择对应 `q1_method_choice`；均匀pillbox与等权聚合对应 `q1_sunshape_weighting_choice`；塔身与集热器几何对应 `q1_tower_shadow_convention`、`q1_tower_height_revision` 和 `q1_receiver_vertical_interval_revision`。

## 2. 论文论证主线

正文必须按以下因果顺序组织：

1. 由日期、时刻和纬度确定太阳高度角、方位角、太阳中心向量与DNI；
2. 由反射定律和镜心指向接收器中心的方向确定镜面法向，再构造有限矩形镜面；
3. 用均匀立体角pillbox表示太阳不是单一平行方向，并对每个太阳盘方向逐条反射；
4. 在同一“镜面位置—太阳方向”联合样本中定义入射阴影、出射遮挡和圆柱命中事件；
5. 以联合事件的概率定义阴影遮挡效率和条件截断效率，保证能量不重复扣损；
6. 与余弦、大气透射和反射率相乘得到单镜效率，再逐时点计算功率后聚合；
7. 连续物理模型确定以后，才介绍M1低差异光线积分、B1基线、收敛和敏感性。

## 4. 可用基线的正确表述

B1与M1共享太阳角、镜面姿态、塔身与集热器几何和功率公式，但用$5\times5$镜面中点网格、中心方向可见性和16个太阳方向形成低分辨率因子化近似。B1年平均综合效率为0.5782，年平均镜场功率为35.3507 MW，分别比M1高0.0059和0.3639 MW。余弦效率完全相同，主要差异来自B1对阴影遮挡和截断边界的粗离散。

论文只能说M1更忠实地数值估计已批准的连续联合光线模型，并通过了收敛检查；不能说M1已由真实电站测量证明“更准确”。

## 6. 题目表格

- 表1：逐月列出综合光学效率、余弦效率、阴影遮挡效率、截断效率和单位面积镜面平均输出热功率。来源为 `q1_month_MM_*` 冻结项。
- 表2：列出年平均综合光学效率、余弦效率、阴影遮挡效率、截断效率、镜场年平均输出热功率和单位面积年平均输出热功率。来源为 `q1_annual_*` 冻结项。
- 方法对照表：只为说明数值离散近似的影响，使用 `q1_baseline_annual_*` 与 `q1_main_baseline_abs_delta_*`；不把基线包装成另一种物理模型。

## 7. 必须显式写出的限制

1. “年平均”是题目规定60状态的离散等权平均，不是逐日逐小时气象积分。
2. 镜面是理想平面镜，没有题面外的斜率、面形、跟踪和污染损失。
3. 太阳形状是半角4.65 mrad的均匀pillbox，不包含无参数依据的周日区模型。
4. 题面功率链条只统计到达圆柱侧面的能量，不含接收器吸收和热损失。
5. 收敛和敏感性证明求解器对已定义模型稳定，不等同于真实电站实测验证。
