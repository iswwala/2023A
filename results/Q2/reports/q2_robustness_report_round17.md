# Q2 round17稳健性报告

## 检验对象

本报告只检验最终方案的几何可行性、离散分辨率收敛和随机种子稳定性，不使用已取消的基线比较，也不把未重新运行的历史扰动实验迁移为最终证据。

## 检验结果

| 风险 | 检验 | 观测值 | 状态 |
|---|---|---:|---|
| 几何非法 | 场界、100 m禁布区、离地、间距、塔位 | 2983面全部通过 | PASS |
| 对称性破坏 | 东西镜像未配对数 | 0 | PASS |
| 分辨率误差 | 16×8至32×16年功率相对差 | 0.010936% | PASS |
| 月度离散误差 | 12个月单位面积功率最大相对差 | 0.082442% | PASS |
| 随机种子离散 | 四种子功率标准差/极差 | 0.013955/0.038709 MW | PASS |
| 容量边界 | 最小单种子功率 | 60.003732 MW | CONDITIONAL |

四种子均达到60 MW，且两级分辨率满足预先登记的收敛阈值，因此正式数值可用于输出。但容量裕量明显小于种子极差，说明该方案贴近约束边界。建模者已通过`q2_round17_final_result_acceptance`接受这一边界特征；论文必须披露，不得扩展成工程冗余充分的结论。

## 限制

检验不覆盖题面未规定的跟踪误差、镜面斜率误差、接收器吸收率或更大太阳形状扰动。结论只适用于当前理想平面镜、塔身圆柱和有限圆柱接收器口径。

证据：`results/Q2/experiments/round17_zoned_formal/metrics/q2_zoned_formal.json`。
